# 11 — UI Requirements

## Nguyên tắc

- React UI **chỉ đọc** game state từ engine.
- Dispatch action qua command (không mutate engine state trực tiếp).
- Tất cả UI responsive (mobile-friendly từ đầu, dù là desktop game).
- Font CJK cho tên NPC (Google Font: Noto Sans CJK hoặc tương đương).
- Theme: tu tiên (màu trầm, vàng/đỏ, texture giấy dó).

## Layout

### Top-level

```
┌─────────────────────────────────────────────────┐
│  HUD Bar (HP, MP, Realm, Day/Hour, Menu button) │
├─────────────────────────────────────────────────┤
│                                                 │
│                                                 │
│         Game View (Map / Combat)                │
│                                                 │
│                                                 │
├─────────────────────────────────────────────────┤
│  Event Log (collapsible, last 5 lines)          │
└─────────────────────────────────────────────────┘
```

Modal/overlay cho Dialog, Character Panel, Relationship Graph, Save/Load.

## Map Screen

### Render

- PixiJS canvas full width.
- Tile map + sprite + animation.
- Camera follow player (smooth).
- Zoom: scroll wheel (1x - 3x).

### Input

| Action | Control |
|---|---|
| Move | WASD / Arrow keys |
| Click-to-move | Click tile hợp lệ |
| Interact NPC | Click NPC hoặc E khi adjacent |
| Open menu | ESC / Tab |
| Pause | Space |
| Speed up | Shift (2x / 4x world tick) |

### HUD

- HP bar + numeric
- MP bar + numeric
- Realm + layer
- Day/Hour
- Mini-map (top-right, optional v0.3)
- Notification icon (event mới)

### Interaction prompt

Khi player adjacent NPC interactable:
```
[E] Nói chuyện với Lý Thanh Vân
[F] Tấn công
[T] Trao đổi
```

### NPC indicator

- Hover NPC: tooltip (tên, realm, affinity summary, grudge count).
- NPC hostile: viền đỏ.
- NPC ally: viền xanh.
- NPC có quest: icon trên đầu (v0.4+).

## Combat Screen

### Layout

```
┌─────────────────────────────────────────────────┐
│ Turn Order (avatar + name)                       │
├─────────────────────────────────────────────────┤
│                                                  │
│   [Enemy F1] [Enemy F2] [Enemy F3]              │
│   [Enemy B1] [Enemy B2] [Enemy B3]              │
│                                                  │
│   ──────────────  Battle Grid  ──────────────   │
│                                                  │
│   [Player F1] [Player F2] [Player F3]           │
│   [Player B1] [Player B2] [Player B3]           │
│                                                  │
├─────────────────────────────────────────────────┤
│ Action Bar (AP indicator)                        │
│ [Attack 1AP] [Skill ▼] [Defend] [Item] [Escape] │
├─────────────────────────────────────────────────┤
│ Combat Log (last 3 lines, scroll for full)      │
└─────────────────────────────────────────────────┘
```

### Target selection

- Click enemy để select target (highlight ring).
- Skill có AoE → preview vùng ảnh hưởng (overlay tint).
- Hover target → tooltip chi tiết (HP, MP, element, status, buff/debuff).

### Status display

Mỗi actor:
- HP bar
- MP bar
- Element icon
- Status icons (stack horizontal, tooltip per icon)
- Buff/Debuff icons

### Combo indicator

- "Combo x2" badge nổi trên actor khi combo > 1.
- Animate pulse khi combo up.

### Action bar

- Buttons disable khi không đủ AP hoặc không hợp lệ.
- Tooltip giải thích skill (damage, cost, element, status chance).
- Keyboard shortcut (1-9 cho skill slot).

### Animation

- Camera shake khi hit lớn.
- Flash white khi crit.
- Slow motion 0.5x khi ultimate skill.
- Death animation + fade.

## Dialog Screen

### Modal

- Portrait NPC trái, portrait player phải.
- Text typewriter effect.
- Choice buttons dưới.

### Types

- Barter (trade UI)
- Romance hint (v0.5+)
- Quest dialog (v0.4+)
- Lore dump (long text)

### Memory reference

NPC có thể reference memory:
```
Lý Thanh Vân: "Ngươi đã cứu ta thoát khỏi bọn cướp. Ta không quên."
```

UI highlight từ khóa "cứu" → tooltip link tới memory entry.

## Relationship Screen

### Graph view

- Cytoscape.js hoặc React Flow.
- Node: NPC avatar + name + realm.
- Edge color theo relation type.
- Edge thickness theo strength.

| Type | Color |
|---|---|
| Friend | Xanh lá |
| Enemy | Đỏ |
| Family | Cam |
| Master | Vàng |
| Disciple | Xanh dương |
| Rival | Tím |
| Lover | Hồng |
| Sworn Brother | Cyan |

### Controls

- Pan: drag canvas.
- Zoom: scroll.
- Search NPC by name.
- Filter: faction, relation type, grudge only.
- Click node: detail panel (NPC info + grudge list + memory summary).

### Detail panel

Slide từ phải khi click node. Hiện:
- Avatar lớn
- Stats
- Traits
- States
- Relation list (tới NPC khác)
- Grudge list (với player)
- Memory entries
- Last interaction day

## Save/Load Screen

### Layout

- Slot grid (3 manual + 1 auto).
- Mỗi slot card: location, day/hour, player level, screenshot thumbnail (optional).
- Buttons: Load / Save / Delete / Rename.

### Confirm dialog

- Overwrite slot? Yes/No.
- Delete save? Yes/No (cảnh báo).
- Load incompatible version? Show diff, cho player chọn.

## Character Panel

- Player stats (HP, MP, attack, defense, speed, crit...).
- Realm + layer + exp progress.
- Skills learned (slot, level).
- Traits.
- States.
- Inventory grid.

## Settings

- Volume (BGM, SFX).
- Text speed.
- Language (VI, EN).
- Keybind remap (optional).
- Save data export/import (debug).

## Accessibility

- Color-blind friendly palette option.
- Text size scale.
- Auto-pause khi window unfocus.
- Keyboard fully usable, không bắt buộc mouse.

## Performance UI budget

- React render budget: 16ms / frame.
- PixiJS render: 16ms / frame riêng (WebGL).
- Modal open animation < 200ms.
- Action button feedback < 50ms (instant).
